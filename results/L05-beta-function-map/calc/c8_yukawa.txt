1. Operator selection (hypercharge + SU(2) doublet count + colour); third generation
   SM (one doublet H; H^c = i sigma2 H* has Y=-1/2 and is the SAME field):
     Q u x: allowed with ['H']
     Q d x: allowed with ['Hc']
     L e x: allowed with ['Hc']
   -> with one doublet, u-type mass needs H, d-type and lepton masses need its conjugate H^c: the SM is forced to use both.
   SUSY (holomorphic W: chiral superfields only, no conjugates). Second doublet = conjugate-type H_d (Y=-1/2):
     Q u x: ['H']
     Q d x: ['Hc']
     L e x: ['Hc']
   Second doublet = duplicate H' (Y=+1/2):
     Q u x: ['H', 'Hp']
     Q d x: []
     L e x: []
   -> with a duplicate, y_b = y_tau = 0 is forced in W; with the conjugate-type H_d all three SM Yukawas map one-to-one.
   In a NON-SUSY theory a duplicate H' (Y=+1/2) can give d, e masses through H'^c: H_d <-> H'^c is a field redefinition.
   So conjugate vs duplicate is distinguishable only on the SUSY side (holomorphy fixes which superfield carries Y=-1/2).

2. Higgsino anomalies (LH Weyl higgsinos; SM fermions are anomaly-free by themselves)
   one SM generation: Tr Y^3 = Tr Y = SU(2)^2U(1) = SU(3)^2U(1) = 0, doublets = 4 (x3 generations = 12, even)
   H~ only                 : Tr Y^3 = 1/4, Tr Y = 1, SU(2)^2U(1) = 1/4, Witten doublets added = 1 (odd)
   H~ + H~_d (conjugate)   : Tr Y^3 = 0, Tr Y = 0, SU(2)^2U(1) = 0, Witten doublets added = 2 (even)
   H~ + H~' (duplicate)    : Tr Y^3 = 1/2, Tr Y = 2, SU(2)^2U(1) = 1/2, Witten doublets added = 2 (even)
   -> only the conjugate pair cancels all anomalies; the duplicate cancels Witten parity but not Tr Y^3, Tr Y, SU(2)^2U(1).
      The anomaly-free pair H~_u, H~_d is one Dirac fermion whose particle and antiparticle carry H and H^c charges.

3. One-loop Yukawa betas from component formulas
   Yukawa part of 16pi^2 beta_y / y, coefficients of (y_t^2, y_b^2, y_tau^2):
     SM   : y_t (9/2, 3/2, 1), y_b (3/2, 9/2, 1), y_tau (3, 3, 5/2)
     2HDM : y_t (9/2, 1/2, 0), y_b (1/2, 9/2, 1), y_tau (0, 3, 5/2)
     DUP  : y_t (9/2, 1/2, 0), y_b (1/2, 9/2, 1), y_tau (0, 3, 5/2)
   SM reproduces the standard one-loop result y_t(3/2 y_t^2 - 3/2 y_b^2 + Y2(S)), Y2(S)=3y_t^2+3y_b^2+y_tau^2, etc. (asserted)
   2HDM-II (H_u, H_d with Y=-1/2) and duplicate (H, H' with Y=+1/2, down via H'^c): identical (asserted) - field redefinition.
   decomposition (asserted):  2HDM-II = fermion legs + own-doublet leg;  SM = fermion legs + Y2(S) + vertex
     identification terms SM - 2HDM-II: {'y_t': (0, 1, 1), 'y_b': (1, 0, 0), 'y_tau': (3, 0, 0)}
     = [Y2(S) - gamma(own doublet)] + vertex, vertex = -2 y_b^2 in beta_t, -2 y_t^2 in beta_b, 0 in beta_tau
   type-I 2HDM (H in both Yukawas via H and H^c, extra doublet H2 Yukawa-free): Yukawa part identical to the SM,
     including the vertex term (asserted). The vertex and Y2(S) cross terms track 'one field in both Yukawas'.
   sum rule: Y2(S)_SM = gamma_Yuk(H_u) + gamma_Yuk(H_d) = 3y_t^2 + (3y_b^2 + y_tau^2): the SM Higgs leg sees both
     MSSM Higgs legs because H^c is the conjugate of the same field. The vertex term exists only for that reason
     (it is a charged-scalar exchange between the y_t and y_b vertices, which share the single H).
   MSSM (Yukawa part): y_t (6, 1, 0), y_b (1, 6, 1), y_tau (0, 3, 4)
   MSSM = 2 x (fermion-leg terms) + (own-doublet leg), vertex 0 (non-renormalisation)  [asserted]
   So under H -> H_u, H^c -> H_d:  fermion legs DOUBLE exactly; the SM Higgs leg Y2(S) SPLITS into gamma(H_u)+gamma(H_d)
   (each Yukawa keeps only its own doublet's share); the SM vertex term (-2) is DROPPED.
   gauge part, one loop: SM -3 sum_{fermion legs} C,  MSSM -2 sum_{all three legs} C
     y_t: SM -17*g1**2/20 - 9*g2**2/4 - 8*g3**2,  MSSM -13*g1**2/15 - 3*g2**2 - 16*g3**2/3,  MSSM - (2/3) SM = -3*g1**2/10 - 3*g2**2/2 (= -2 C(Higgs leg))
     y_b: SM -g1**2/4 - 9*g2**2/4 - 8*g3**2,  MSSM -7*g1**2/15 - 3*g2**2 - 16*g3**2/3,  MSSM - (2/3) SM = -3*g1**2/10 - 3*g2**2/2 (= -2 C(Higgs leg))
     y_tau: SM -9*g1**2/4 - 9*g2**2/4,  MSSM -9*g1**2/5 - 3*g2**2,  MSSM - (2/3) SM = -3*g1**2/10 - 3*g2**2/2 (= -2 C(Higgs leg))
   -> fermion-leg gauge terms scale by 2/3 (not 2); the Higgs leg is new; C(H) = C(H^c): the gauge part is conjugation-blind.
