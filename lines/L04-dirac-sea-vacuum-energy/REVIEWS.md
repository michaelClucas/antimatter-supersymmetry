2. **major** - WORK.md:50, :52-61 (scheme table) and :183 (H2 checklist). The claim that "Str m^4 = 0 and Str m^4 ln m^2 = 0 are the scheme-independent tests" is wrong for the fourth condition. In MS-bar the finite part is Sum s_i m_i^4 (ln m_i^2/mu^2 - c_i) with c = 3/2 (scalars, fermions) and 5/6 (vectors). Even with Str m^4 = 0 this equals Str m^4 ln m^2 + (2/3) Sum_V g_V m_V^4, not Str m^4 ln m^2; in DR-bar the vector constant is 3/2 and the extra term disappears; in the 3-momentum cutoff the vector is three scalar d.o.f. and the constant is again different. So the condition for rho = 0 is regulator dependent beyond Str m^4. Fix: state the fourth condition as scheme-dependent (H2 says so is allowed) and note that only Str m^4 = 0 (equivalently mu-independence of the one-loop term) is scheme-independent. The negative result is unaffected because Str m^4 fails.

5. **minor** - WORK.md:123. "A_vac(mu) at mu >> m_t is the MS-bar beta function of the cosmological-constant counterterm" is incorrect. Str M^4 at phi = v mixes all of these. So "a zero of A_vac would say the high-scale cc counterterm stops running" is wrong (beta_Omega is nonzero whenever m^2 is).
