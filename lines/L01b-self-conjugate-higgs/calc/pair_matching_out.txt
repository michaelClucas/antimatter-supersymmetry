PART 4. SUSY comparison target: supertrace identities, top/stop and electroweak sectors
====================================================================================================
   STr M^2 (stops 2 complex x 3 col = 12 real dof; top 12 dof) = 6*m_Q**2 + 6*m_U**2  (phi-independent: no Lambda^2)
   ln(Lambda^2) coefficient of d^2V/dphi^2 at phi=0: -3*y**2*(A_t**2 + m_Q**2 + m_U**2)/(8*pi**2)
     -> delta m_H^2 (|H|^2 coeff = (1/2) d^2V/dphi^2... per ln Lambda): -(3 y^2/8pi^2)(m_Q^2 + m_U^2 + A_t^2) ln(Lambda/m)
        the standard MSSM result (e.g. Martin, hep-ph/9709356). Only the SOFT mass, which splits stop from top, survives.
   Higgs scalars (8 real, D-term quartics) Tr M_S^2 (field-dependent) = (3*g**2 + gp**2)*(v_d**2 + v_u**2)/4
   gauge bosons  3 x Tr M_V^2                                 = 3*(3*g**2 + gp**2)*(v_d**2 + v_u**2)/4
   neutralinos (4 Majorana, self-conjugate) 2 Tr M^+M (field-dep.) = (g**2 + gp**2)*(v_d**2 + v_u**2)
   charginos   (2 Dirac, charged pairs)     4 Tr X^+X (field-dep.) = 2*g**2*(v_d**2 + v_u**2)
   STr (bosons - fermions) = 0
   -> In SUSY the SM-like boson loops (W, Z, h, Goldstones) are themselves cancelled, by electroweakinos.
      The self-conjugate bosons (Z, photon, neutral Higgs) are partnered by self-conjugate (Majorana) neutralinos;
      the charged pairs (W+-, H+-) by charged Dirac pairs (charginos). Self-conjugacy is carried across the multiplet.
   boson side total = (3*g**2 + gp**2)*(v_d**2 + v_u**2);  fermion side total = (3*g**2 + gp**2)*(v_d**2 + v_u**2)
   (Tr Y = 0 over Hu, Hd; sfermion D-terms cancel separately since Tr Y = 0 per generation.)
   Charge-resolved (neutral = self-conjugate states; charged = particle/antiparticle pairs):
     neutral bosons  Z + neutral Higgs scalars: (g**2 + gp**2)*(v_d**2 + v_u**2)   vs neutralinos (Majorana): (g**2 + gp**2)*(v_d**2 + v_u**2)   difference 0
     charged bosons  W+- + charged Higgs scalars: 2*g**2*(v_d**2 + v_u**2)   vs charginos (Dirac): 2*g**2*(v_d**2 + v_u**2)   difference 0
