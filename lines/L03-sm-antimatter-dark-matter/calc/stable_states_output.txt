1. 'R-parity' of every SM field: R = (-1)^{3(B-L)+2s}
   Q_L  : 3(B-L)+2s = 2  -> R = +1
   u^c  : 3(B-L)+2s = 0  -> R = +1
   d^c  : 3(B-L)+2s = 0  -> R = +1
   L_L  : 3(B-L)+2s = -2  -> R = +1
   e^c  : 3(B-L)+2s = 4  -> R = +1
   g    : 3(B-L)+2s = 2  -> R = +1
   W    : 3(B-L)+2s = 2  -> R = +1
   B    : 3(B-L)+2s = 2  -> R = +1
   H    : 3(B-L)+2s = 0  -> R = +1
   Every SM field (and its antiparticle, which flips B,L but not 2s mod 2) has R=+1, so every
   SM state, elementary or composite, has R=+1. R-parity restricted to the SM is the identity
   map: this is the identity (-1)^{2s} = (-1)^{3B+L} (spin-statistics + SM charge assignments).
   It cannot stabilise anything beyond what (-1)^F, B, L already do.

2. Anomaly coefficients per generation, global U(1) x (gauge)^2, x gravity^2, U(1)^3 (no nu_R):
   B   : SU(2)^2   1/2  SU(3)^2     0  U(1)_Y^2   -1/2  grav^2    0  self^3    0
   L   : SU(2)^2   1/2  SU(3)^2     0  U(1)_Y^2   -1/2  grav^2    1  self^3    1
   B-L : SU(2)^2     0  SU(3)^2     0  U(1)_Y^2      0  grav^2   -1  self^3   -1
   B and L each have SU(2)^2 and U(1)_Y^2 anomalies (sphalerons/instantons violate B+L).
   B-L: gauge anomalies cancel -> conserved by all SM gauge dynamics. Without nu_R its
   mixed gravitational anomaly is -1 per generation (-3 total): B-L is a global symmetry with a
   gravitational anomaly (irrelevant numerically, but 'exact' is only exact w.r.t. SM gauge fields).
   Also: whether B-L survives neutrino-mass generation is unknown (Majorana mass breaks it by 2; A2).

3. Lightest SM state in each sector of exactly/effectively conserved charges (T=0):
   Q!=0               e-/e+ (Q=-+1)                                                 m=    0.511 MeV  charged: couples to photons, not DM (E5)
   B=0,L!=0,Q=0       lightest nu / nubar                                           m_nu<0.45 eV  neutral, stable, HOT relic (see 4)
   F odd, Q=0, B=0    lightest nu / nubar                                           m_nu<0.45 eV  same
   B=+-1              p / pbar                                                      m=  938.272 MeV  charged
   B=+-1, Q=0         H / anti-H atom                                               m=  938.783 MeV  neutral but ionised before z~1100: baryonic (see 5)
   B=+-2, Q=0         2H / anti-2H atom (or S/Sbar if it exists and m_S<1876.12 MeV)  m= 1876.124 MeV  baryonic unless S exists
   all zero           photon                                                        m=    0.000 MeV  radiation
   Theorem used: in a theory whose only exact/effective conserved charges are Q, B, L, (-1)^F
   and 4-momentum, the only absolutely stable single-particle states are the lightest state in each
   charge sector; heavier states decay into lighter ones of equal charges (phase space permitting).
   Unstable SM states (mu, tau, pi, K, n [880 s], W, Z, H, t, glueball-like states, positronium,
   protonium, sphalerons) cannot be relic DM (lifetimes << 13.8 Gyr).
   Topological defects: vacuum manifold of SU(2)xU(1)->U(1)_em is S^3; pi_0=pi_1=pi_2(S^3)=0,
   so no stable domain walls, strings or monopoles in the SM.

   sum m = 0.059 eV -> Omega_nu h^2 = 6.33e-04  (fraction of Omega_c h^2 = 0.005)
   sum m = 0.072 eV -> Omega_nu h^2 = 7.73e-04  (fraction of Omega_c h^2 = 0.006)
   sum m = 0.120 eV -> Omega_nu h^2 = 1.29e-03  (fraction of Omega_c h^2 = 0.011)
   sum m = 1.350 eV -> Omega_nu h^2 = 1.45e-02  (fraction of Omega_c h^2 = 0.121)
   Even at the KATRIN-limit-saturating 3x0.45 eV, Omega_nu h^2 = 0.0145 < 0.12, and nu are hot
   (relativistic at matter-radiation equality for m < ~1 eV); hot DM at this level is excluded by
   structure formation. A lepton asymmetry (antineutrino excess) only raises n_nu via a chemical
   potential, bounded by N_eff (E6); it does not make them cold.

5. CMB baryon loading R = 3 rho_b / (4 rho_gamma) at z*=1090:
   Omega_b h^2 = 0.02237: R = 0.622
   If the 0.12 of DM were antibaryonic plasma (pbar, e+): R = 3.958
   Thomson cross section sigma_T = (8pi/3) alpha^2/m_e^2 depends on charge squared and mass,
   identical for e+ and e- (CPT, B2/B6); pbar-e+ Coulomb coupling identical to p-e-. So the
   acoustic physics measures rho(baryons)+rho(antibaryons) and gets 0.0224, not 0.142.
   Ratio of R values = 6.4: excluded by the observed odd/even peak heights.
